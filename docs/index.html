CANDO Cooperative Agentic Network for Layout Design Optimization

Real sites have irregular boundaries, vehicles that must get through, and design manuals full of rules. We introduce ALPS-Bench, a benchmark of 1,000 real facility layouts scored by design-manual compliance. We also present CANDO, a training-free team of agents that plans, edits, and checks layouts with deterministic tools until they comply.

TL;DR

Layout generation has outgrown distribution matching.

Most layout benchmarks place boxes on rectangular canvases and score results with FID or IoU. These metrics reward similarity to the training set, so a valid but unusual design gets marked down. Real asset design is harder. The site boundary is irregular, groups of elements need consistent orientations, placements depend on where the access points are, and vehicles must be able to drive through the finished layout.

We address this with a benchmark that scores each layout against a structured design manual instead of against other layouts, and a method that splits the reasoning across specialised agents. Deterministic tools handle the spatial arithmetic that LLMs get wrong.

The benchmark

ALPS-Bench: Asset Layout Planning & Synthesis

Annotators traced polygons directly from the original CAD drawings of operational sites, so each layout reflects the site as built. The task: given the premise, its access points, and a list of elements with fixed shapes, find a position 𝐩i and an orientation θi for every element.

The design manual

Containment

Every placed element lies inside the premise: Ωi⊆𝒫.

Non-overlap

No two surface elements intersect: Ωi∩Ωj=∅. Underground facilities may lie beneath surface elements.

Routing feasibility

For every vehicle scenario, a collision-free path runs from an Entrance, through the required waypoints, to an Exit. Service areas are drive-through.

Compositionality · CO

Elements of the same class form clusters. Odd-sized service clusters form a line; even-sized ones form a compact block (2×2, 2×3, …). Parking bays form strict lines.

Orientation · OR

Within a group, every element is parallel or perpendicular to the others, within 5°.

Proximity · PR

Stacking against the site boundary or the Shop, 3 m egress zones in front of parking bays, isolation of HGV service areas, and service-area hubs placed next to underground facilities.

Routing scenarios

Motion planning

Voronoi-based routing checks

  1. Premise. Start from the layout of the scenario.
  2. Inflate & sample. Grow every obstacle by a margin ϵ that depends on the vehicle, then sample seed points on the grown borders.
  3. Medial axis. Build a Voronoi diagram from the seeds. Its ridges run down the middle of each free corridor, as far from obstacles as possible.
  4. Route. Attach the Entrance, the waypoints, and the Exit to that graph, then run a shortest-path search.

Scoring: constraint satisfaction, not similarity

HCM

HCM=0.2HCg+0.8HCf

Geometric validity (area-scaled penalties for overlaps and out-of-bounds parts) plus the fraction of feasible routing scenarios. A missing or wrongly sized element sets HCM to 0.

SCM

SCM=0.6PR+0.3CO+0.1OR

Soft constraints from the design manual. The weights are proportional to the number of rules in each category.

RE

RE=13(PL+MN+PC)

Path length, manoeuvrability (number of sharp turns), and path clearance, each compared with the hidden ground truth. A score of 0.5 means parity with the ground truth.

AGG

AGG=12(CS+RE),CS={SCMHCM=10.5HCM⋅SCMotherwise

An invalid layout keeps at most half of its soft-constraint score.

The method

CANDO: agents that cooperate, tools that verify

Language models are weak at coordinate arithmetic. CANDO lets the models make the strategic decisions (what to move, and why) and leaves the geometry to deterministic tools. The method works in two phases: an in-context seed, then a cooperative refinement loop.

Click an agent to see what it does.

Search

Parallel branching with blockwise best-of-N

CANDO adapts CoDe’s blockwise sampling from diffusion models. At the start of each block, the current best layout is copied into N branches. Each branch runs B history-aware planning–generation–verification steps with its own memory. At the end of the block, the branch with the highest verified score is kept and copied again. This lets CANDO explore different repairs in parallel without committing to one too early.

Illustration with simulated scores. With B = T, CoDe reduces to plain best-of-N. The paper uses N=4, B=10, K=6, W=6, T=20.

Generator

An ensemble of eight repair strategies

Each branch gets strategies at random. Some follow the plan and some ignore it. Without this mix, the regression rate climbs from 7.0% to 18.4%.

Algorithm 1 · CANDO 
Require ℐ, 𝒟dev, N, B, K, W, T
ℋ(0) ← ∅ ;  t ← 0
(𝐪̄(0), ℱ(0)) ← Verifier({ICLInit(ℐ, 𝒟dev)})
while t ≤ T − B do
    {ℋ(t)n, ℱ(t)n, 𝐪(t)n}Nn=1 ← Replicate(ℋ(t), ℱ(t), 𝐪̄(t))
    for b = 0, …, B−1 do                        ▷ ∀ n ∈ [N], in parallel
        ℋ(t+b+1)n ← Historian(ℋ(t+b)n, ℱ(t+b)n, W)
        Π(t+b+1)n ← Planner(𝐪(t+b)n, ℱ(t+b)n, ℋ(t+b+1)n)
        𝒬(t+b+1)n ← Generator(𝐪(t+b)n, Π(t+b+1)n, K)
        (𝐪̄(t+b+1)n, ℱ(t+b+1)n) ← Verifier(𝒬(t+b+1)n)
    t ← t + B
    (𝐪̄(t), ℱ(t), ℋ(t)) ← BoN({𝐪̄(t)n, ℱ(t)n, ℋ(t)n}Nn=1)
end while, return 𝐪̄(T)

Results

Better layouts in fewer steps

Both CANDO variants significantly outperform every baseline on AGG, CS, and RE (paired Wilcoxon, Holm-corrected p≤0.0059). This includes models trained on ALPS-Bench and a GPT-5.2 agent that has CANDO’s own tools.
